# Mar Azul

Application gratuite pour apprendre le kriolu du Cap-Vert (variante de Santiago, Sotavento), avec Djodje le requin.
Interface en français, anglais, portugais, néerlandais et espagnol.

Le site est un seul fichier, `index.html`, publié avec GitHub Pages.
Il est généré à partir des sources du projet (`build.py`) ; ne pas le modifier à la main.
